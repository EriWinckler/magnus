# eriwinckler-site

## TL;DR
Personal site of Eridan Winckler. Built with create-react-app and deployed by Netlify from `main` to
https://eriwinckler.netlify.app. The tag and branch `v1` hold the original design with updated content.

## Commands
```bash
yarn install --frozen-lockfile
yarn build
CI=true yarn test --watchAll=false
```
