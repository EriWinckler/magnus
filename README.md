# eriwinckler-site

## TL;DR
Personal site of Eridan Winckler. Built with Vite and React and deployed by Netlify from `main` to
https://eriwinckler.netlify.app (build settings in `netlify.toml`, Node version in `.nvmrc`). The tag and
branch `v1` hold the original design with updated content.

## Commands
```bash
npm ci
npm run dev      # local dev server
npm run build    # production build into dist/
npm test
npm run lint
```
